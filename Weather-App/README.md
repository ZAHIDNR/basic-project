## 📖 About the Project

I built this as part of [The Odin Project](https://www.theodinproject.com/) while learning about working with APIs.
The app pulls weather data and related GIFs using two different APIs — just to show that I understood how to work with external data sources.

It’s not meant to be perfect or polished — just something that reflects what I’ve learned at this point in my journey.

> I’m currently learning full-stack web development, but later I plan to explore beyond the web too. This is just the beginning.

---

## 🔧 What It Does

* 🌍 Fetches real-time weather data from the **Visual Crossing API**
* 🎞️ Displays weather-related **GIFs** using the **Giphy API**
* 🌡️ Lets users **toggle between Fahrenheit and Celsius**
* 🌆 Shows basic weather info like temperature, humidity, wind speed, and pressure
* 🧼 Simple and clean UI with a touch of gradient goodness

---

**APIs Used:**

* [Visual Crossing Weather API](https://www.visualcrossing.com/weather-api)
* [Giphy API](https://developers.giphy.com/)
